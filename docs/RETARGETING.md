# Retargeting

Initial animation evaluation supports FK with local S/Rx/Ry/Rz/T, exact hierarchy and inverse binds. Same-skeleton CHR0 import uses exact unique names and a fingerprint; it does not invoke anatomical mapping. Missing tracks/bones are actionable errors.

Next criterion M1.D is explicit fingerprinted manual mapping and a restricted tested rotation-delta transfer. Anatomical inference, rest-axis correction, proportions, twists, IK/contact, rebinding and facial/material mapping are still required by REQ-07 and remain on the roadmap. Generic original rigs are never named exact game profiles. Animation-only transfer must retain target mesh/binds unchanged.
