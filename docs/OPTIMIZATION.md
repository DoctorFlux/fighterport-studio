# Optimization

No animation reducer or geometry reducer is delivered. Preserve high-quality source data. Current native tests report actual CHR0 bytes and quarter-frame decode error rather than claiming fewer keys means smaller native files. Future reducer acceptance must protect locked/hold/impact/contact/loop/winding/root keys and evaluate native interpolation between keys, end effectors and skinned vertices. Do not silently relax size/fidelity conflicts or invent per-game budgets. Automatic geometry reduction remains deferred.
