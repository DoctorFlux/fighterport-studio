## Static native color/alpha reference surface — 2026-10-17

A separate contextual Browser action evaluates a bounded static plane using native TEV metadata; the 3D model renderer remains the isolated-sampler approximation described above. Genuine original fixture tests cover two separately filtered textures, three stages and a native color/alpha constant. Each sampler is evaluated before stage math, so this is not a pre-flattened composite texture used as a model material. Native stage records, raw color/alpha/indirect words, constants, alpha/blend and depth/cull metadata survive FPWORK saves. Unsupported data remains linked to the original native source.

Declared CPU reference subset: UV0/direct static matrices (Maya without rotation, XSI/3dsMax); independent U/V clamp/repeat/mirror; nearest/linear magnification; clamped add/subtract/bias/scale and supported constant selectors; alpha comparisons and opaque or standard source-alpha output. Quotas: 256-square output, at most 16 active stages/1,048,576 fragment-stages, 32 MiB texture bytes. Transformed texel footprints that require minification reject. Signed/unclamped/compare stages, raster input, swaps, indirect/projected coordinates, other blend modes, lighting, depth/cull, GPU fixed-point precision and animated material channels are unevaluated. Unsupported actions are disabled with reasons. No material/model native exporter was added.
